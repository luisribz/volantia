Import / Export

Imports merge: nothing you added by hand is lost.

Flights from another app: export the CSV from myFlightradar24 (flightdiary) or MyFlightPath and import it here. You see what changes before anything is saved: new flights are added, flights already here are filled in (number, times, airline), never doubled.

First time here? Import data/volantia-seed.json. Export a backup now and then — this device is the only copy unless cloud sync is on.

Cloud sync

Keeps every device in sync through a private, encrypted GitHub gist. On a new phone, the token alone brings everything back.

Create one at github.com/settings/tokens → Generate new token (classic) → tick only gist → Generate → copy. Your data is encrypted with a key made from the token before it leaves the device, so nobody with the gist link can read it. Keep the token safe — a new token can't read the old cloud copy. Your devices keep their own copy, and "Overwrite cloud" re-uploads from one of them.

Danger zone

Removes everything from this device. The cloud copy (if any) stays.
