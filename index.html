Cloud sync

Keeps every device in sync through a private, encrypted GitHub gist. Change phones and all you need is your token.

Create one at github.com/settings/tokens → Generate new token (classic) → tick only gist → Generate → copy. Your data is encrypted with a key derived from the token before it leaves the device, so nobody with the gist link can read it. Keep the token safe — regenerating it makes the cloud copy unreadable (your devices keep their own copy, and reconnecting re-uploads from there).

Import / Export
